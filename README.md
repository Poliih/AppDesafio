# 🎯 Pregação Challenge — Sorteador de Palavras

Aplicativo Android criado como **desafio de pregação**, no qual o pregador recebe **duas palavras aleatórias** para desenvolver sua mensagem, **sem preparação prévia**.  
O objetivo é estimular a criatividade, improvisação e conexão espiritual durante a ministração.

---

## 📌 Funcionalidades

- ✏️ **Adicionar palavras personalizadas** à lista.
- 🎲 **Gerar duas palavras aleatórias** para o desafio.
- 📜 **Histórico de desafios** realizados.
- 🎯 **Tela verde de destaque** para exibir as palavras do momento.
- 🔄 **Trocar de seções facilmente** (Adicionar, Gerar, Histórico).

---

## 🚀 Como Usar

1. Abra o aplicativo.
2. No menu **Adicionar Palavra**, insira todas as palavras que deseja utilizar no desafio.
3. Vá para o menu **Gerar Desafio** e clique em "Gerar".
4. Duas palavras aleatórias aparecerão na **tela verde**.
5. Use essas palavras como base para a pregação.
6. Consulte o histórico para rever desafios passados.

---

## 🛠️ Tecnologias Utilizadas

- **Kotlin** — Linguagem principal do desenvolvimento Android.
- **Android View Binding** — Ligação direta entre código e layouts.
- **Random** — Lógica de sorteio aleatório.
- **XML** — Definições de layout e configurações do Manifest.
